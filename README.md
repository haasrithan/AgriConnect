AgriConnect is a web-based platform built to support farmers with tools and services that streamline agricultural activities. The platform is developed using PHP, Python, HTML, and CSS, offering a responsive and functional user experience.

Features
User-Friendly Interface: Built with PHP and styled using CSS for smooth navigation and accessibility.

Database Integration: Uses test_db.php for MySQL database connectivity and data handling.

Admin Dashboard: A dedicated admin panel (in the admin/ directory) for managing content and users.

Authentication System: Supports user login and registration to ensure secure access.

git clone https://github.com/haasrithan/AgriConnect.git
Set Up the Environment:

Ensure PHP, MySQL, and optionally Python are installed.

Use XAMPP/WAMP/LAMP for running a local server.

Import the database if a .sql file is provided, and configure the connection in test_db.php.

Run the Application:

Place the project folder in the server's root directory (htdocs for XAMPP).

Open your browser and navigate to localhost/AgriConnect/index.php.

Usage
Farmer Interface: Access tools and services to support day-to-day agricultural tasks.

Admin Panel: Navigate to /admin to log in and manage backend operations.
